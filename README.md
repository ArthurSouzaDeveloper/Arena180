# FreeBarber

Plataforma de contratação de barbeiros freelancer por barbearias.

Barbearias contratam barbeiros freelancer para períodos determinados (ex: um final de
semana). O barbeiro define o valor da diária; a plataforma soma uma comissão sobre esse
valor e processa o pagamento com repasse automático via Mercado Pago.

Veja o design e o plano de implementação em `docs/superpowers/specs/`.

## Desenvolvimento

```bash
npm install
npm run dev
```
